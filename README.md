# 柔神 · 星河来信

这是纯前端单文件页面，不需要后端、账号、数据库或构建工具。

## 本地预览

直接双击 `index.html` 即可在浏览器中打开。

如果希望测试“分享链接”功能，需要通过 HTTP 访问，例如在本目录运行任意静态文件服务器。

## 发布

把整个 `roushen` 文件夹交给 Cloudflare Pages、Netlify、Vercel 或任意静态托管即可。入口文件为 `index.html`。

## 已包含

- 自动持续烟花
- “点亮夜空”触发大型多段烟花、星光辉光与专属祝福
- “初见、温柔、此刻”三颗星互动仪式，完成后触发终场烟花
- 点亮进度保存在本机浏览器，并提供重新点亮
- 点击/触摸后连续放烟花，按住或滑动时烟花跟随指针位置
- 心形、环形、垂柳形和圆形烟花
- 星河、流星、鼠标光晕和入场动画
- “给柔神”的专属感谢信
- 可选的合成环境音、星铃与烟花音效
- “留一句话”入口，每次提交都会新增一颗可查看的星星`r`n- 默认包含“天天开心、平安喜乐、自由自在、万事顺意、被爱包围”五颗祝福星
- 星空留言会保存在本机浏览器
- 根据晨间、白昼、傍晚和深夜自动切换天空色调
- 连续点击标题五次或长按三秒可触发隐藏彩蛋
- 回忆星匣支持本机选择照片、自动压缩并保存
- 手机竖屏与桌面端适配
- 分享按钮
- 减少动态效果的无障碍适配

编辑 `index.html` 中的“柔神”“温柔有神 · 自由有光”和星河来信文案即可定制内容。
